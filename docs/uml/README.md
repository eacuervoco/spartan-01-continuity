ContinuitY Platform.

Archivo:

## Alcance

Los modelos de F0.7 representan dominio y comportamiento funcional.

No constituyen todavía:

- arquitectura de software;
- modelo físico de base de datos;
- clases Python definitivas;
- endpoints API;
- componentes AWS;
- arquitectura RAG;
- arquitectura de agentes.

Estas decisiones serán refinadas en las siguientes etapas del proyecto.
